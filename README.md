# BluePop

Beautiful, customizable Bluetooth popups for Android, with smooth animations, elegant designs, and real-time device information.

Built with Kotlin and Jetpack Compose.

## Features

- **Bluetooth popups**: a polished popup that appears for your Bluetooth devices
- **Customizable**: choose the look that suits you
- **Smooth animations**: fluid, modern motion throughout
- **Real-time device information**: see connection details at a glance



## Download

Get the latest APK from the [Releases page](https://github.com/Umangnamdeo/BluePoP/releases).

1. Download the `.apk` file from the newest release.
2. Open it on your phone. If asked, allow installs from your browser or file manager.
3. Launch BluePop and grant the permissions it asks for.
